# ⚡ PowerBank

Прошивка для DIY power bank на базе **ESP8266** / **ESP32** / **ESP32-S3** с веб-интерфейсом мониторинга, OTA-обновлениями и файловым менеджером.

---

## Возможности

### Мониторинг батареи
- **INA219** - измерение напряжения, тока, мощности и заряда
- Расчёт остаточной ёмкости в Ah с учётом заданной ёмкости аккумулятора
- Определение режима: зарядка / разряд / ожидание
- Три уровня тревоги: норма / низкий заряд (≤20%) / критично (≤10%)

### Веб-интерфейс
- **Неоновая кибер-эстетика** - тёмный фон с cyan/violet-подсветкой
- Дашборд с графической полосой заряда и цветовой индикацией
- Настройки Wi-Fi, времени, часового пояса
- Управление яркостью ST7789 и подсветкой LCD1602

### Сеть
- **Wi-Fi**: STA (подключение к роутеру) или AP (своя точка доступа)
- **NTP** - синхронизация времени (pool.ntp.org)
- **mDNS** - доступ по имени хоста (`powerbank.local`)
- **Часовые пояса** - выбор TZ через веб-интерфейс

### OTA-обновления
- **Проверка обновлений** через GitHub API (сравнение дат коммитов)
- **Раздельные обновления**: firmware и littlefs показываются независимо
- **Прямые ссылки** на скачивание `.bin` без архивов
- **Автопроверка** раз в 24 часа
- **Ручная проверка** по кнопке

### Файловый менеджер
- Просмотр файлов LittleFS
- Загрузка / скачивание / удаление

### Дисплеи
- **LCD1602** (I2C) - на всех платформах
- **ST7789** (SPI) - только на ESP32 / ESP32-S3
- Автоматическая ротация страниц с IP, зарядом, временем

## Аппаратная часть

### Поддерживаемые платформы

| Платформа | Статус | Примечания |
|---|---|---|
| **ESP8266** (Wemos D1 mini) | ✔️ | Базовая конфигурация |
| **ESP32** | ✔️ | + ST7789, больше RAM |
| **ESP32-S3** | ✔️ | + PSRAM, USB-CDC |

### Компоненты

| Компонент | Обязателен | Назначение |
|---|---|---|
| ESP8266 / ESP32 | ✔️ | Микроконтроллер |
| INA219 | ✔️ | Датчик тока/напряжения (I2C, адрес `0x40`) |
| LCD1602 + PCF8574 | ⚙️ | Дисплей 16×2 (I2C, адрес `0x27` или `0x3F`) |
| ST7789 | ⚙️ | Цветной TFT (только ESP32) |
| Кнопка | ⚙️ | Ручное управление |
| Аккумулятор 18650 / Li-Po | ✔️ | Источник питания |

## Схема подключения

### ESP8266 (Wemos D1 mini)

INA219 (I2C): LCD1602 (I2C):
VCC - 3.3V VCC - 5V (или 3.3V)
GND - GND GND - GND
SDA - D2 (GPIO4) SDA - D2 (GPIO4)
SCL - D1 (GPIO5) SCL - D1 (GPIO5)

### ESP32

INA219 + LCD1602 (общая I2C-шина):
VCC - 3.3V
GND - GND
SDA - GPIO21
SCL - GPIO22

ST7789 (SPI):
BLK - GPIO27 (подсветка, PWM)
CS - GPIO15
DC - GPIO2
RST - GPIO4
SDA - GPIO23 (MOSI)
SCL - GPIO18 (SCK)
VCC - 3.3V
GND - GND


### ESP32-S3

I2C: SDA - GPIO8, SCL - GPIO9
SPI: BLK - GPIO4
